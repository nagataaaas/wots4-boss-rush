# ボスラッシュ

[English](README.en.md) | [更新履歴](CHANGELOG.md)

> [!NOTE]
> この Mod は [Steam 版『侍道4』](https://store.steampowered.com/app/312780/4/?l=japanese)専用です。

真ルートの結末「希望の光」を見た後、墓場の幽霊に話しかけると「強者たちと戦う」が選べるようになります。三勢力や町の強者たちと、誰もいない墓場で次々に戦えます。

## 機能

### 「強者たちと戦う」が出る条件

墓場の幽霊の選択肢に「強者たちと戦う」が加わるのは、次をすべて満たすときです。

- 結末「希望の光」を見たことがある（いまの周回でも、これまでの周回でもかまいません）
- ボスラッシュの最中ではない

「強者たちと戦う」を選ぶと、戦う相手を選ぶ選択肢が出ます。

- なりわい「四天王 対 四人組」「阿弥浜八人衆」をどちらもクリアしたことがなければ、三勢力の選択肢（攘夷・幕府・外国）がすぐに出ます。
- どちらかをクリアしたことがあれば、まず「三勢力の強者と戦う」「町の強者と戦う」から選びます。「町の強者と戦う」の中身は、クリアしたなりわいで決まります。

| 選択肢 | 出る条件 |
| --- | --- |
| 攘夷の強者と戦う | いつでも |
| 幕府の強者と戦う | いつでも |
| 外国の強者と戦う | いつでも |
| 四天王(熊神除く)と戦う | なりわい「四天王 対 四人組」をクリアしたことがある |
| 四人組と戦う | なりわい「四天王 対 四人組」をクリアしたことがある |
| 八人衆と戦う | なりわい「阿弥浜八人衆」をクリアしたことがある |

なりわいのクリアは、これまでの周回も含めて数えます。

### ボスラッシュの流れ

- 選ぶと「強者たちが墓場で待っている……」と出て、誰もいない墓場へ移ります。移るときに時間は進みません。
- 段が始まるたびに、相手の名前が出ます。強者たちはカメラの後ろから現れ、主人公に向かってきます。
- その段の強者をすべて倒すと、3 秒後に次の段が始まります。すべての段を倒すと「強者たちをすべて倒した」と出ます。
- ボスラッシュの間は、歩いて墓場から出られません。すべて倒した後に歩いて出ると、いつもの墓場に戻ります。ファストトラベルでは、選んだ場所へ移ります。
- 主人公が倒れると、ボスラッシュはそこで終わり、いつものゲームの流れに戻ります。
- 強者が 60 秒のあいだ主人公に近づいてこないとき（たどり着けない場所に出たときなど）は、強者たちが消え、ボスラッシュが終わります。
- ボスラッシュで倒した強者は、本編の扱いでは死にません。人物の生死や物語の進み方は変わりません。

## インストール

### 自動インストール（推奨）

1. ゲームを終了してください。
2. [WayOfTheSamurai4ModInstaller.exe](https://github.com/nagataaaas/wots4-mods/releases/latest/download/WayOfTheSamurai4ModInstaller.exe) をダウンロードして実行してください。
   - 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。
   - 管理者として実行してよいかの確認が出たら、「はい」を押してください（ゲームのフォルダに書き込むためです）。
3. 画面の案内に沿って進め、Mod の一覧で `boss_rush` を選んでください。↑↓ で移動し、Space で選び、Enter で確定します。

ModLoader も一緒に入ります。更新も同じ手順でできます。

## アンインストール

1. ゲームを終了してください。
2. `{侍道4インストールフォルダ}/mods/boss_rush/` フォルダを削除してください。

この Mod はセーブに何も書き足さないので、外した後もそのままのセーブで遊べます。
